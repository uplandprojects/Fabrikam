A simple React "Hello World" application with dark/light mode toggle! 🚀

## 📖 Overview

Fabrikam is a minimal React application that displays "Hello World" with a beautiful gradient design and theme switching capability. This project serves as a starter template for React development using webpack and Jest.

## ✨ Features

- 🌓 **Dark/Light Mode Toggle** - Switch between dark and light themes
- 🎨 **Gradient Styling** - Beautiful gradient text effect
- ⚡ **Fast Development** - Hot reloading with webpack dev server
- 🧪 **Testing Ready** - Jest and React Testing Library configured

## 🚀 Getting Started

### Prerequisites

- Node.js 18.x or higher

### 📥 Installation

```bash
# Clone the repository
git clone https://github.com/uplandprojects/Fabrikam.git

# Navigate to the project directory
cd Fabrikam

# Install dependencies
npm install

# Start the development server
npm run dev
```

## 💻 Usage

Once installed, access the application at `http://localhost:3000`

Click the sun/moon icon in the top right corner to toggle between light and dark modes.

## 🧪 Testing

```bash
# Run unit tests
npm test
```

## 🏗️ Building

```bash
# Build for production
npm run build
```

The production build will be output to the `dist/` directory.
