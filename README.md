Welcome to **Fabrikam** - a simple React application starter project! 🚀

## 📖 Overview

Fabrikam is a minimal React application that displays "Hello World" with a dark/light mode toggle. It's built with React 18 and webpack, providing a clean foundation for building modern web applications.

## ✨ Features

- ⚛️ **React 18** - Built with the latest React version
- 🎨 **Dark/Light Mode** - Toggle between dark and light themes
- 📦 **Webpack** - Modern bundling and development server
- 🧪 **Jest Testing** - Comprehensive test setup with React Testing Library
- 📱 **Responsive Design** - Works beautifully on all devices

## 🚀 Getting Started

### Prerequisites

- Node.js 18.x or higher
- npm 8.x or higher

### 📥 Installation

```bash
# Clone the repository
git clone https://github.com/uplandprojects/Fabrikam.git

# Navigate to the project directory
cd Fabrikam

# Install dependencies
npm install

# Start the development server
npm run dev
```

## 💻 Usage

Once installed, access the application at `http://localhost:3000`

The app displays a "Hello World" message with a dark/light mode toggle button in the top-right corner.
